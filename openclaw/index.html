QCAI Momentum

Deploy your high-agency AI Chief of Staff in minutes.

1. Download Workspace Artifacts

Save these files to your ~/.openclaw/workspace/ directory. They define your agent's soul and execution pipeline.

Download SOUL.md Download HEARTBEAT.md Download TOOLS.md (Win) Download TOOLS.md (Unix)

2. Deploy Decision Engine

Save your choice of logic engine to ~/.openclaw/skills/momentum/.

Node.js Engine Recommended

High compatibility, no external dependencies required (works with standard OpenClaw install).

Download logic.js Download search.js

Python Engine Legacy

Requires Python 3.8+ and Pip installed in your system PATH.

Download logic.py

3. Configure Discovery Tools

Run these commands in your terminal to enable Google Maps and Perplexity reasoning.

# Set Discovery API Keys (v2026.3.24+)
openclaw config set skills.entries.goplaces.apiKey "YOUR_GOOGLE_KEY"
openclaw config set skills.entries.perplexity.apiKey "YOUR_PERPLEXITY_KEY"

# Optional: Set Network Mode
# "local" is recommended for Tailscale/VPN users.
openclaw config set gateway.mode "local"

# Apply Changes
openclaw gateway restart
Tailscale Users: Ensure "allowTailscale": true is set in your openclaw.json and the Tailscale IP range (100.0.0.0/8) is added to trustedProxies.

4. Verify Insight Loop

Monitor your logs to ensure the QCAI App is successfully submitting sensor data:

openclaw logs --follow | grep "heartbeat"

You should see heartbeat: started and successful session completions from OpenClaw-Mobile-AI.
