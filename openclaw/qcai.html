Momentum Gateway Setup Guide

The QCAI App (iOS/Android) sends sensor data. The Gateway uses logic to decide, and Tools to discover solutions.

🚀 Deployment Steps

  1. Sync Knowledge & Logic files (Section 1).
  2. Connect Google Maps & Perplexity (Section 2) so the Gateway can see and think.
  3. Activate the Momentum Agent (Section 3).

1. Download Required Files

A. Knowledge (Save to ~/.openclaw/workspace/):

SOUL.md HEARTBEAT.md TOOLS.md

B. Engine (Save to ~/.openclaw/skills/momentum/):

logic.py

2. Connect Discovery Tools (Maps + Perplexity)

The Gateway needs Google Maps for physical locations and Perplexity for high-agency reasoning. Run these on your Gateway:

# Enable Google Maps (For physical discovery/GPS)
openclaw config set tools.maps.provider "google"
openclaw config set tools.maps.api_key "YOUR_GOOGLE_MAPS_KEY"

# Enable Perplexity (For reasoning and smart recommendations)
openclaw config set tools.search.provider "perplexity"
openclaw config set tools.search.api_key "YOUR_PERPLEXITY_KEY"

# Ensure Gateway allows data from the QCAI phone app
openclaw config set gateway.mode remote
openclaw gateway restart

3. Activate the Momentum Agent

This command registers your logic engine and knowledge workspace with the Gateway service:

openclaw config set agents.momentum.enabled true
openclaw config set agents.momentum.logic "./skills/momentum/logic.py"
openclaw config set agents.momentum.workspace "./workspace/"
openclaw gateway restart

4. How it Works (The Full Loop)

  1. QCAI App: Reports high stress and location data.
  2. logic.py: Triggers an ALIGN state.
  3. Google Maps: Gateway finds 3 quiet spots within a 5-minute walk.
  4. Perplexity: Gateway evaluates which of those 3 spots matches your SOUL.md preferences best.
  5. Insight: Phone displays: "Chief of Staff: You're red-lining. Head to the 4th floor balcony—Google says it's empty, and it's 1 min away."

5. Verify Logic Engine

Run a local test to ensure logic.py is processing sensor data correctly:

cat test_state.json | python3 logic.py
