Momentum Gateway Setup Guide (v2026.3+)

The QCAI App (iOS/Android) transforms your mobile device into a high-fidelity sensor hub. This guide ensures your OpenClaw Gateway correctly processes sensor data via the Insight Loop.

Updated for v2026.3.24: This guide includes the new skills.entries configuration namespace and Node.js logic migration instructions.

1. Deploy Knowledge & Logic

A. Knowledge Base (Save to ~/.openclaw/workspace/)

Ensure these files are present in your workspace. They define the proactivity triggers and tool access rules.

  • HEARTBEAT.md: Defines the logic gating and execution interval.
  • SOUL.md: Provides the persona and high-level behavioral constraints.
  • TOOLS.md: Lists the available discovery tools for the agent.
# Sample HEARTBEAT.md Execution Line
# If using logic.js (Recommended):
15. Execute `node logic.js`.

# If using logic.py:
15. Execute `python3 logic.py`.

B. Decision Engine (Save to ~/.openclaw/skills/momentum/)

The decision engine processes incoming JSON from the app and returns an action (PROTECT, ALIGN, ENHANCE, or SILENCE).

Node.js Preferred: We recommend using the Node.js version (logic.js) as it leverages the existing OpenClaw environment without requiring a Python installation. 
// Save as ~/.openclaw/skills/momentum/logic.js
const fs = require('fs');
function calculate() {
    const data = JSON.parse(fs.readFileSync(0, 'utf-8'));
    // Simplified logic: High stress triggers ALIGN
    const stress = data.user_state?.stress_score || 0;
    const decision = stress > 0.75 ? "ALIGN" : "SILENCE";
    console.log(JSON.stringify({ decision, gap: 999 }));
}
calculate();

2. Configure API Discovery Tools

Run these commands to enable Google Maps and Perplexity reasoning for the "Discovery" phase.

# Set Google Maps API Key
openclaw config set skills.entries.goplaces.apiKey "YOUR_KEY"

# Set Perplexity Search API Key
openclaw config set skills.entries.perplexity.apiKey "YOUR_KEY"

# Gateway Mode
# Use "remote" for public access, or "local" if using Tailscale/VPN.
openclaw config set gateway.mode "local"

openclaw gateway restart

3. Security & Connectivity

Tailscale/VPN Users: You can keep gateway.mode local. Ensure your OpenClaw config includes "allowTailscale": true and that the Tailscale IP range (100.0.0.0/8) is in your trustedProxies.

4. End-to-End Verification

Check the Gateway logs to ensure the connection is active and data is flowing.

openclaw logs --follow | grep "heartbeat"

Look for the heartbeat: started log and subsequent sessions from userAgent: OpenClaw-Mobile-AI.
