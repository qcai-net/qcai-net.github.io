Momentum Gateway Setup Guide

The QCAI App (iOS/Android) acts as your sensor hub. The Gateway uses HEARTBEAT.md instructions to monitor your state and trigger logic.py.

🚀 Deployment Steps

  1. Download Knowledge & Logic files (Section 1).
  2. Connect Google Maps & Perplexity (Section 2).
  3. Verify Connection (Section 3) to ensure the Gateway sees your files.

1. Download Required Files

A. Knowledge Base (Save to ~/.openclaw/workspace/):

SOUL.md HEARTBEAT.md TOOLS.md

B. Decision Engine (Save to ~/.openclaw/skills/momentum/):

logic.py

2. Connect API Discovery Tools

Run these on your Gateway to enable Google Maps and Perplexity reasoning:

openclaw config set tools.maps.provider "google"
openclaw config set tools.maps.api_key "YOUR_GOOGLE_MAPS_KEY"
openclaw config set tools.search.provider "perplexity"
openclaw config set tools.search.api_key "YOUR_PERPLEXITY_KEY"
openclaw config set gateway.mode remote
openclaw gateway restart

3. Verify the "Chief of Staff" Connection

Before testing with the QCAI app, verify that OpenClaw is correctly detecting your files:

openclaw workspace list
Success looks like: If you see SOUL.md and HEARTBEAT.md in the output, the Gateway is ready to process your data autonomously.

4. The Insight Loop

  1. QCAI App: Streams sensor data (Stress, GPS, Battery) to the Gateway.
  2. Gateway Agent: Reads HEARTBEAT.md, identifies the need for a state check, and runs logic.py.
  3. Discovery: If logic.py returns ALIGN, the Gateway uses Google Maps to find a quiet location.
  4. Delivery: The Gateway pushes the final high-agency recommendation back to your phone.

5. Local Engine Test

Ensure logic.py is working independently of the network:

cat test_state.json | python3 ~/.openclaw/skills/momentum/logic.py
