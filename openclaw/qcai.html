Momentum Gateway Setup Guide

The QCAI App (iOS/Android) is your mobile sensor hub. The OpenClaw Gateway is the intelligence layer that processes your state and discovers real-world solutions.

🚀 Deployment Steps

  1. Sync Knowledge & Logic files (Section 1).
  2. Connect Google Maps & Perplexity (Section 2) for discovery.
  3. Activate the Momentum Agent (Section 3).

1. Download Required Files

A. Knowledge Base (Save to ~/.openclaw/workspace/):

SOUL.md HEARTBEAT.md TOOLS.md

B. Decision Engine (Save to ~/.openclaw/skills/momentum/):

logic.py

2. Connect Discovery Tools (Maps + Perplexity)

To find specific locations and provide high-agency reasoning, the Gateway needs its "Eyes" (Google Maps) and "Brain" (Perplexity). Run these on your Gateway:

# 1. Enable Google Maps (Physical Location Discovery)
openclaw config set tools.maps.provider "google"
openclaw config set tools.maps.api_key "YOUR_GOOGLE_MAPS_KEY"

# 2. Enable Perplexity (High-Agency Reasoning)
openclaw config set tools.search.provider "perplexity"
openclaw config set tools.search.api_key "YOUR_PERPLEXITY_KEY"

# 3. Enable Remote Access for QCAI Apps
openclaw config set gateway.mode remote
openclaw gateway restart

3. Activate the Momentum Agent

This command tells the Gateway to use your logic.py engine and workspace files for active monitoring:

openclaw config set agents.momentum.enabled true
openclaw config set agents.momentum.logic "./skills/momentum/logic.py"
openclaw config set agents.momentum.workspace "./workspace/"
openclaw gateway restart

4. The Insight Loop

  • QCAI App: Reports high stress and current location.
  • logic.py: Analyzes the priority stack and flags an ALIGN state.
  • Discovery: The Gateway uses Google Maps to find quiet spots and Perplexity to vet them against your SOUL.md.
  • Final Delivery: The phone displays: "Chief of Staff: You're red-lining. Head to the 4th floor balcony—it's empty and 1 min away."

5. Verification (The Acid Test)

Test the logic.py decision engine locally to ensure it handles stress correctly:

cat test_state.json | python3 logic.py
Expected Outcomes:
• Stress > 0.75 → ALIGN
• Gap < 20m → PROTECT
• High confidence + Big gap → ENHANCE
