Deploying Your OpenClaw Context OS

This guide provides everything you need to connect your QCAI App OpenClaw Context OS to your personal OpenClaw Gateway. You must choose whether to run your Gateway's Decision Engine using Node.js (Recommended) or Python.

Important: We strongly recommend using the Node.js skills, as they do not require a separate Python environment and are fully compatible with your existing OpenClaw installation.

1. Download Required Files

Depending on your choice of environment (Node.js vs Python), download the corresponding files below:

Option A: Node.js Skills (Recommended)

Download these files to use the native JavaScript decision engine.

📥 SOUL.md 📥 HEARTBEAT.md 📥 TOOLS.md (Windows) 📥 unixTOOLS.md (Mac/Linux) 📥 logic.js 📥 search.js

Placement:

  • SOUL.md → ~/.openclaw/workspace/SOUL.md
  • HEARTBEAT.md → ~/.openclaw/workspace/HEARTBEAT.md
  • TOOLS.md (or unixTOOLS.md) → ~/.openclaw/workspace/TOOLS.md
  • logic.js → ~/.openclaw/skills/momentum/logic.js
  • search.js → ~/.openclaw/skills/momentum/search.js
CRITICAL STEP: You MUST open search.js in a text editor (like Notepad or VS Code) and replace "YOUR_PERPLEXITY_KEY" on Line 1 with your actual Perplexity API key before the discovery engine will work.

Option B: Python Skills (Legacy)

If you already have a configured Python 3 environment, you can use the original python scripts.

📥 SOUL.md 📥 HEARTBEAT.md 📥 TOOLS.md (Windows) 📥 unixTOOLS.md (Mac/Linux) 📥 logic.py

Placement:

  • logic.py → ~/.openclaw/skills/momentum/logic.py

Required Edit: Open HEARTBEAT.md and change step #15 to execute python3 logic.py instead of node logic.js.

2. Configure Gateway Settings

Run these commands in your terminal to configure the gateway port, security, and the built-in API keys.

# Disable device pairing (allows mobile app connection)
openclaw config set plugins.entries.device-pair.enabled false

# Set authentication to token mode
openclaw config set gateway.auth.mode "token"

# Bind listener to localhost on port 18789
openclaw config set gateway.port 18789
openclaw config set gateway.url "http://127.0.0.1:18789"

# Set Google Maps API Key (Built-in Skill)
openclaw config set skills.entries.goplaces.apiKey "YOUR_GOOGLE_MAPS_KEY"

# Apply changes by restarting the gateway
openclaw gateway restart

3. Start the Tailscale Proxy

To expose your gateway securely to the internet (so your mobile app can reach it), run a Tailscale Funnel. Run this exact command to forward traffic to port 18789:

tailscale serve --bg --https=443 http://127.0.0.1:18789

4. Connect Your Mobile App

To connect the iOS/Android app to your newly configured gateway, you will need your Tailscale endpoint URL and your Gateway Authentication Token.

  1. Run tailscale serve status to get your public Tailscale URL.
  2. Run openclaw status --deep to retrieve your Gateway Token.
  3. Enter both pieces of information into your mobile app settings.
