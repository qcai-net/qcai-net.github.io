Momentum Gateway Setup Guide

Turn your iOS app into a Context-Aware Decision Engine. The Gateway evaluates your time, stress, and attention and decides: protect, reset, enhance—or stay silent.

Endpoint: Your iOS app must send JSON to /v1/state on this Gateway.

1. Folder Structure

~/.openclaw/
└── skills/
    └── momentum/
        ├── logic.py
        ├── SOUL.md
        ├── HEARTBEAT.md
        └── TOOLS.md

2. Download Required Files

Place these files into the momentum folder:

SOUL.md HEARTBEAT.md TOOLS.md (Windows) TOOLS.md (Mac/Linux)

Mac/Linux: rename unixTOOLS.md → TOOLS.md

3. Create the Decision Engine (logic.py)

import sys, json, datetime

def calculate():
    try:
        data = json.load(sys.stdin)
        now = datetime.datetime.fromisoformat(data["metadata"]["current_timestamp"].replace("Z",""))

        events = data.get("temporal_intelligence", {}).get("upcoming_events", [])
        gap_min, is_remote, is_low_effort = 999, True, False

        if events:
            e = events[0]
            start = datetime.datetime.fromisoformat(e["start_date"].replace("Z",""))
            gap_min = (start - now).total_seconds() / 60
            loc = e.get("location", "").lower()
            title = e.get("title", "").lower()

            is_remote = any(k in loc for k in ["http", "zoom", "teams"])
            is_low_effort = any(k in title for k in ["webinar", "lecture", "sync", "listen"])

        state = data.get("user_state", {})
        stress = state.get("stress_score", 0.5)
        distracted = state.get("attention", {}).get("mode") == "DISTRACTED"
        battery = state.get("device", {}).get("battery_level", 1.0)

        if gap_min < 20:
            return out("PROTECT", gap_min)

        if (distracted and stress > 0.5) or stress > 0.75:
            return out("ALIGN", gap_min)

        conf = 0.0
        if gap_min > 60: conf += 0.4
        if is_remote: conf += 0.2
        if is_low_effort: conf += 0.1
        if stress < 0.5: conf += 0.2
        if battery > 0.3: conf += 0.1

        return out("ENHANCE" if conf >= 0.8 else "SILENCE", gap_min)

    except:
        return out("SILENCE", 0)

def out(d, g):
    print(json.dumps({"decision": d, "gap": g}))

if __name__ == "__main__":
    calculate()

5. Enable Discovery (Optional)

openclaw config set tools.google_maps.api_key "YOUR_API_KEY"

Enable Google Places API in Google Cloud.

6. What Happens Next?

When decision = ENHANCE, the Gateway:

  • Searches one nearby place (cafe, park, library)
  • Applies safety time buffer
  • Sends ONE recommendation to your iOS app

7. Architecture Summary

Priority: PROTECT → ALIGN → ENHANCE → SILENCE

The system only speaks when it improves your day.
