Momentum Gateway Setup Guide

Follow these steps to ensure your OpenClaw Gateway correctly links your logic.py and .md files to the QCAI App.

🚀 Complete Deployment

  1. Download Knowledge & Logic (Section 1).
  2. Connect Google Maps & Perplexity (Section 2).
  3. Run the Glue Commands (Section 3) to link everything.

1. Download Required Files

A. Knowledge (Save to ~/.openclaw/workspace/):

SOUL.md HEARTBEAT.md TOOLS.md

B. Engine (Save to ~/.openclaw/skills/momentum/):

logic.py

2. Connect API Discovery Tools

openclaw config set tools.maps.provider "google"
openclaw config set tools.maps.api_key "YOUR_GOOGLE_MAPS_KEY"
openclaw config set tools.search.provider "perplexity"
openclaw config set tools.search.api_key "YOUR_PERPLEXITY_KEY"

3. The "Glue" (Connecting Files to Logic)

Crucial: Run these commands so OpenClaw knows to read your files and run your script when phone data arrives:

# 1. Point the Gateway to your .md files
openclaw config set workspace.path "~/.openclaw/workspace/"

# 2. Register logic.py as the primary decision engine
openclaw config set gateway.hooks.on_data "python3 ~/.openclaw/skills/momentum/logic.py"

# 3. Set to Remote Mode and Restart
openclaw config set gateway.mode remote
openclaw gateway restart

4. Final Test

To verify the Gateway is "hearing" the logic, run this on your PC:

cat test_state.json | python3 ~/.openclaw/skills/momentum/logic.py
