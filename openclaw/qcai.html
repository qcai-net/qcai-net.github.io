Momentum Gateway Setup Guide

Deploy a high-agency "Chief of Staff" on your OpenClaw Gateway to optimize your time and mental state.

🚀 Quick Start (2 Minutes)

  1. Create folder: ~/.openclaw/skills/momentum/
  2. Download SOUL.md, HEARTBEAT.md, and your OS-specific TOOLS.md.
  3. Create logic.py (paste code from Section 3).
  4. Configure Discovery (Section 4) to enable the iOS app.
  5. Run the Acid Test (Section 5) and expect ALIGN.

3. The Engine (logic.py)

Create logic.py and paste this code. It handles the Priority Stack (PROTECT > ALIGN > ENHANCE):

import sys, json, datetime

def calculate():
    try:
        data = json.load(sys.stdin)
        now = datetime.datetime.fromisoformat(data["metadata"]["current_timestamp"].replace("Z",""))
        events = data.get("temporal_intelligence", {}).get("upcoming_events", [])
        gap_min, is_remote, is_low_effort = 999, True, False
        if events:
            e = events[0]
            start = datetime.datetime.fromisoformat(e["start_date"].replace("Z",""))
            gap_min = (start - now).total_seconds() / 60
            loc, title = e.get("location", "").lower(), e.get("title", "").lower()
            is_remote = any(k in loc for k in ["http", "zoom", "teams"])
            is_low_effort = any(k in title for k in ["webinar", "lecture", "sync", "listen"])
        
        state = data.get("user_state", {})
        stress, distracted = state.get("stress_score", 0.5), state.get("attention", {}).get("mode") == "DISTRACTED"
        battery = state.get("device", {}).get("battery_level", 1.0)

        if gap_min < 20: return out("PROTECT", gap_min)
        if (distracted and stress > 0.5) or stress > 0.75: return out("ALIGN", gap_min)

        conf = 0.0
        if gap_min > 60: conf += 0.4
        if is_remote: conf += 0.2
        if is_low_effort: conf += 0.1
        if stress < 0.5: conf += 0.2
        if battery > 0.3: conf += 0.1

        return out("ENHANCE" if conf >= 0.8 else "SILENCE", gap_min)
    except: return out("SILENCE", 0)

def out(d, g): print(json.dumps({"decision": d, "gap": g}))

if __name__ == "__main__": calculate()

4. Mandatory: Setup Discovery (iOS App)

The iOS app will not function unless the Gateway is broadcasting its presence via mDNS.

A. Enable Network Discovery

Run these commands in your terminal to allow the iOS app to find the gateway:

openclaw config set gateway.mode remote
openclaw config set gateway.discovery.enabled true
openclaw config set gateway.discovery.name "My-Momentum-Gateway"
openclaw gateway restart

B. Network Requirements

  • Same WiFi: iPhone and Gateway PC must be on the same local network.
  • Firewall: Ensure UDP Port 5353 is open (mDNS/Bonjour).
  • Linux Users: Ensure Avahi is running: sudo systemctl enable --now avahi-daemon

C. Pairing

Once you see your Gateway in the iOS app settings, tap it. To approve the link, run:

openclaw nodes approve --all

5. The Acid Test

Save this as test_state.json and run the command for your OS:

{
  "metadata": { "current_timestamp": "2026-03-26T14:30:00Z" },
  "temporal_intelligence": {
    "upcoming_events": [{ "title": "Webinar", "start_date": "2026-03-26T16:00:00Z", "location": "http://zoom.us" }]
  },
  "user_state": { "stress_score": 0.85, "attention": { "mode": "DISTRACTED" }, "device": { "battery_level": 0.9 } }
}

Windows

Get-Content test_state.json | python logic.py

macOS / Linux

cat test_state.json | python3 logic.py
Expected Outcomes:
• High stress → ALIGN
• Low stress + big gap → ENHANCE
• Tight schedule (< 20m) → PROTECT
• Everything else → SILENCE
