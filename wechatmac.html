🍏 QCAI WeChat Bridge (macOS)

Utilizing the Model Context Protocol (MCP) for seamless integration.

Requirements

  • macOS: 14.0 (Sonoma) or newer.
  • Python: 3.12 or higher installed.
  • WeChat for Mac: Installed and currently running.
Critical: On macOS, you must grant Accessibility and Screen Recording permissions to your Terminal for the AI to interact with WeChat.

1 Install WeChat-MCP

Open your Terminal (Terminal.app or iTerm2) and install the native MCP server:

pip install wechat-mcp-server

2 Grant System Permissions

  1. Go to System Settings > Privacy & Security.
  2. Select Accessibility and add your Terminal app.
  3. Select Screen Recording and add your Terminal app.

Note: These permissions are required so the bridge can "read" the WeChat window to find messages.

3 Configure the QCAI Skill

Navigate to ~/.openclaw/skills/ and create a folder named qcai-wechat-mcp. Inside, create your manifest:

SKILL.md 
---
name: qcai-wechat-mcp
description: "macOS Native WeChat Bridge using Accessibility API."
metadata:
  openclaw:
    emoji: 🍎
    category: Communication
---

# QCAI macOS Bridge
This skill connects OpenClaw to the local WeChat-MCP server running on your Mac.

## Instructions
The agent will automatically use the `wechat-mcp` command to fetch and send messages.

4 Register the Server

Tell OpenClaw to start the WeChat-MCP server whenever it boots. Add this to your OpenClaw config file:

{
  "mcpServers": {
    "wechat-mcp": {
      "command": "wechat-mcp",
      "transport": "stdio"
    }
  }
}

Final Step: Verify

  1. Restart your OpenClaw Gateway on your Mac.
  2. Open the QCAI App on your iPhone.
  3. Ask the agent: "Check my latest WeChat messages".
  4. If the Mac asks for permission, click Allow.
