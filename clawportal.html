🌐 QCAI Portal Setup & Examples 🌐 QCAI 门户设置与示例

The QCAI Portal allows you to transform your OpenClaw Gateway into a visual command center. It serves dashboards, documents, and GUI interfaces directly to your QCAI App. Looking for the flagship example? Check our Use Case Examples below. QCAI 门户允许您将 OpenClaw 网关转换为可视化指挥中心。它直接向您的 QCAI 应用程序提供仪表板、文档和 GUI 界面。正在寻找旗舰示例？请查看下方的 使用案例示例。

Step 1: Create the Portal Directory 步骤 1：创建门户目录 

mkdir -p ~/.openclaw/workspace/portal

Step 2: The Portal Server (dashboard.py) 步骤 2：门户服务器 (dashboard.py)

Create dashboard.py in your portal/ directory. Running this dynamic server allows your mobile app to send commands back to the computer (e.g., triggering WeChat messages or clearing logs). 在 portal/ 目录中创建 dashboard.py。运行动态服务器允许您的移动应用程序将命令发送回计算机（例如，触发微信消息或清除日志）。 

import http.server
import socketserver
import json
import subprocess
import os

PORT = 18790

class PortalHandler(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header('Access-Control-Allow-Origin', '*')
        self.send_header('Access-Control-Allow-Methods', 'GET, POST, OPTIONS')
        self.send_header('Access-Control-Allow-Headers', 'Content-Type')
        super().end_headers()

    def do_OPTIONS(self):
        self.send_response(200)
        self.end_headers()

    def do_POST(self):
        if self.path == '/api/exec':
            content_length = int(self.headers['Content-Length'])
            post_data = self.rfile.read(content_length)
            data = json.loads(post_data.decode('utf-8'))
            cmd = data.get('cmd')
            try:
                # Skill directory for WeChat bridge
                skills_dir = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", "skills", "wechat"))
                import re
                unbuffered_cmd = re.sub(r'(python(?:3|[\.\d]*|\.exe)?)\s', r'\1 -u ', cmd, count=1, flags=re.IGNORECASE)
                result = subprocess.run(unbuffered_cmd, shell=True, capture_output=True, text=True, cwd=skills_dir, timeout=35)
                try:
                    response_data = json.loads(result.stdout)
                except ValueError:
                    response_data = {"status": "error", "output": result.stdout, "debug": result.stderr}
                self.send_response(200)
                self.send_header('Content-type', 'application/json')
                self.end_headers()
                self.wfile.write(json.dumps(response_data).encode('utf-8'))
            except Exception as e:
                self.send_response(500)
                self.end_headers()
                self.wfile.write(json.dumps({"status": "error", "message": str(e)}).encode('utf-8'))

if __name__ == "__main__":
    os.chdir(os.path.dirname(os.path.abspath(__file__)))
    socketserver.TCPServer.allow_reuse_address = True
    with socketserver.TCPServer(("", PORT), PortalHandler) as httpd:
        print(f"==========================================")
        print(f"🚀 QCAI Multi-App Portal Active")
        print(f"📡 Portal:  http://127.0.0.1:{PORT}")
        print(f"------------------------------------------")
        print(f" Apps mapped on Launcher:")
        print(f" - /index.html  -> Operation Hub")
        print(f" - /wechat.html -> WeChat GUI")
        print(f"==========================================")
        httpd.serve_forever()

    • 3. Claude Code Remote Access (Terminal) 3. Claude Code 远程访问 (终端)

    Claude Code is a powerful agentic terminal tool. By hosting a web-accessible terminal on your OpenClaw Gateway computer, you can use Claude's coding abilities directly from your mobile device. Claude Code 是一个强大的代理终端工具。通过在您的 OpenClaw 网关计算机上托管一个可从 Web 访问的终端，您可以直接从移动设备使用 Claude 的编码能力。

    🛠️ Setup on Gateway PC:在网关 PC 上设置：
    1. Install ttyd:安装 ttyd：
      Choose the command for your OS:选择适合您系统的命令：
      • Windows: scoop install ttyd (or download the .exe from GitHub)(或从 GitHub 下载 .exe)
      • macOS: brew install ttyd
      • Linux: sudo apt install ttyd (Ubuntu/Debian)(Ubuntu/Debian)
    2. Run the Command:运行命令：
      Open your terminal (PowerShell, Terminal, or Bash) on the Gateway Computer and run:在网关计算机上打开终端（PowerShell、Terminal 或 Bash）并运行： 
    ttyd -p 18790 -W claude
    ⚠️ Port Note:端口提示：
    We are using Port 18790 here for direct compatibility with the QCAI App's default Portal button. If you are also running the dashboard.py launcher, make sure to stop it first or run ttyd on a different port like 18791. 我们在此处使用 端口 18790 以直接兼容 QCAI 应用程序的默认门户按钮。如果您还在运行 dashboard.py 启动器，请务必先停止它，或者在 18791 等不同端口上运行 ttyd。
    📱 Access via QCAI App:通过 QCAI 应用访问：
    1. Open the QCAI App on your iPhone/Android.在您的 iPhone/Android 上打开 QCAI 应用程序。
    2. Tap the 🏠 **Portal** icon on the bottom navigation bar.点击底部导航栏上的 🏠 **门户** 图标。
    3. From the Operation Hub, tap the 🐚 **Claude Code** card.在操作中心中，点击 🐚 **Claude Code** 卡片。
    💡 Port Customization:端口自定义：
    If you start ttyd on a different port (e.g., 18791), ensure you update the Port Configuration in your QCAI app settings to match. 如果您在不同的端口（例如 18791）上启动 ttyd，请务必更新 QCAI 应用程序设置中的端口配置以进行匹配。
    You now have a full-screen, touch-optimized terminal to run /edit, /test, and /compact commands remotely! 您现在拥有一个全屏、触摸优化的终端，可以远程运行 /edit、/test 和 /compact 命令！

    4. Antigravity IDE: The "Porta" or "Levitation" Bridge 4. Antigravity IDE：“Porta” 或 “Levitation” 桥接

    Antigravity is a powerful agentic IDE. Because it is a heavy GUI application, streaming it directly to mobile can be difficult. Community members use lightweight mobile bridges specifically for this purpose. Antigravity 是一个强大的代理 IDE。因为它是一个大型 GUI 应用程序，直接流式传输到移动设备可能会很困难。社区成员专门为此目的使用轻量级移动桥接器。

    🚀 Option A: Levitation / Porta (Mobile-First)选项 A：Levitation / Porta (移动优先)
    These are open-source mobile interfaces designed to talk to Antigravity's Language Server. Instead of streaming a heavy desktop, they only transfer chat data and code diffs. 这些是开源的移动界面，旨在与 Antigravity 的语言服务器通信。它们不再流传繁重的桌面，而仅传输聊天数据和代码差异。
    🛠️ Setup:设置：
    Run the bridge client on the same machine as Antigravity. It usually exposes a web dashboard on a local port (e.g., 3000). 在运行 Antigravity 的同一台机器上运行桥接客户端。它通常在本地端口（例如 3000）上公开 Web 仪表板。
    📱 Access:访问：
    Point your QCAI app's Portal or Port Configuration to http://<your-tailscale-ip>:3000. 将 QCAI 应用程序的门户或端口配置指向 http://<您的 tailscale-ip>:3000。
    🌐 Option B: Code-Server (VS Code in Browser)选项 B：Code-Server (浏览器中的 VS Code)
    If you are using Antigravity via VS Code extensions, you can run code-server. This renders the entire IDE in a web-compatible format that works perfectly in the QCAI App's web view. 如果您通过 VS Code 扩展使用 Antigravity，则可以运行 code-server。这会以 Web 兼容格式渲染整个 IDE，在 QCAI 应用程序的网页视图中完美运行。
