🌐 QCAI Portal Setup & Examples 🌐 QCAI 门户设置与示例

The QCAI Portal allows you to transform your OpenClaw Gateway into a visual command center. It serves dashboards, documents, and GUI interfaces directly to your QCAI App. Looking for the flagship example? Check out the WeChat Setup Guide to build your first professional automation bridge. QCAI 门户允许您将 OpenClaw 网关转换为可视化指挥中心。它直接向您的 QCAI 应用程序提供仪表板、文档和 GUI 界面。正在寻找旗舰示例？请查看微信设置指南以构建您的第一个专业自动化桥梁。

Step 1: Create the Portal Directory 步骤 1：创建门户目录 

mkdir -p ~/.openclaw/workspace/portal

Step 2: Start the Portal Server 步骤 2：启动门户服务器

Depending on your needs, you can choose between two serving modes: 根据您的需求，您可以选择两种服务模式：

📦 Option A: Static Serving (View Only)选项 A：静态服务 (仅查看)

If you only want to access information generated by the OpenClaw Gateway (e.g., video, audio, or reports), a simple Python web server is enough. 如果您只想访问 OpenClaw 网关生成的信息（例如视频、音频或报告），一个简单的 Python Web 服务器就足够了。 

cd ~/.openclaw/workspace/portal && python -m http.server 18790

⚡ Option B: Dynamic Serving (Remote Control)选项 B：动态服务 (远程控制)

If you want to **send commands** to your computer to perform Windows automation (like controlling WeChat remotely), you MUST use the dashboard.py bridge. 如果您想向计算机**发送命令**以执行 Windows 自动化（如远程控制微信），您必须使用 dashboard.py 桥接程序。

You can find the full source code for dashboard.py in the WeChat Setup Guide. 您可以在 微信设置指南 中找到 dashboard.py 的完整源代码。 
cd ~/.openclaw/workspace/portal && python dashboard.py

🌟 Use Case Examples 🌟 使用案例示例

1. Remote WeChat GUI Control 1. 远程微信 GUI 控制

By placing a specialized index.html in the portal folder, you can control your PC's WeChat from your phone. Sync message history into a beautiful chat interface and reply instantly. 通过在门户文件夹中放置专门的 index.html，您可以从手机控制电脑的微信。将消息历史同步到漂亮的聊天界面中并立即回复。

Follow the WeChat Setup Guide to enable this feature. 按照 微信设置指南 启用此功能。
🎯 The Vision: Virtual WeChat AI Persona愿景：虚拟微信 AI 人格
Combined with OpenClaw skills, you can create a "Virtual Twin" that processes messages in batches, searches history for context, and acts exactly like a human assistant on your behalf. 结合 OpenClaw 技能，您可以创建一个“虚拟双生子”，批量处理消息、搜索历史背景，并代表您像人类助手一样行事。

2. Workflow Output Visualization 2. 工作流输出可视化

If your OpenClaw agent performs a complex task (like generating a market report or a tax summary), it can save the result as an HTML file in the portal/ directory. 如果您的 OpenClaw 代理执行复杂任务（如生成市场报告或税务摘要），它可以将结果保存为 portal/ 目录中的 HTML 文件。

Example: Tap the portal icon to instantly view the tax report your AI agent generated 5 minutes ago while you were away. 示例：点击门户图标，立即查看 AI 代理在您离开时 5 分钟前生成的税务报告。
📡 Troubleshooting: External Access (Tailscale/iOS)疑难解答：外部访问 (Tailscale/iOS)
By default, Windows Firewall blocks incoming connections to new ports even if you are on Tailscale. If your iOS device cannot connect via your Tailscale IP, you must Allow Port 18790 in Windows Firewall. 默认情况下，即使您使用 Tailscale，Windows 防火墙也会阻止对新端口的传入连接。如果您的 iOS 设备无法通过 Tailscale IP 连接，您必须在 Windows 防火墙中允许端口 18790。

Run this command in PowerShell (Admin): 在 PowerShell (管理员) 中运行此命令： 
netsh advfirewall firewall add rule name="QCAI Portal" dir=in action=allow protocol=TCP localport=18790
🔧 How to Access in QCAI App:如何在 QCAI 应用中访问：
  1. Enter your Tailscale IP or MagicDNS in Settings.在设置中输入您的 Tailscale IP 或 MagicDNS。
  2. Tap the 🏠 **Portal** icon on the bottom navigation bar.点击底部导航栏上的 🏠 **门户** 图标。
