QCAI Portal Setup

Follow these steps to enable the QCAI Portal on your OpenClaw Gateway. This allows the QCAI app to securely access dashboards, GUI controls, and generated documents via your private Tailscale network.

Prerequisite: Ensure Tailscale MagicDNS is enabled in your Tailscale Admin Console.

1 Create the Portal Directory

Open your terminal on the Gateway computer and create the folder where assets will be stored:

mkdir -p ~/.openclaw/workspace/portal

2 Start the Asset Server

Run the following command to start the HTTP server on port 18790. This server is only accessible to devices on your Tailnet.

cd ~/.openclaw/workspace/portal && nohup python3 -m http.server 18790 &

3 Configure your QCAI App

In the QCAI App settings, enter your MagicDNS hostname. The app will automatically connect to the following endpoints:

  • Command Center: ws://[hostname]:18789
  • Portal View: http://[hostname]:18790

4 Verification

To test if it's working, create a test file:

echo "<h1>Portal Active</h1>" > ~/.openclaw/workspace/portal/index.html

Now, tap the Portal icon in your QCAI app. You should see "Portal Active" on your screen.
