💬 QCAI WeChat Bridge Setup

This guide allows you to control your Windows WeChat desktop client remotely using your OpenClaw Gateway.

Requirements:
  • Windows PC with WeChat Desktop installed and logged in.
  • Python 3.10+ installed on your Windows machine.

Step 1: Install Automation Driver

Open PowerShell or Command Prompt on your Windows PC and install the WeChat automation driver:

pip install git+https://github.com/JamzYang/wxauto4.git
Troubleshooting 'pip' is not recognized: If you get an error that pip or python is not found, it means Python is not in your system PATH.
Fix: Re-run the Python Windows installer, and at the very bottom of the first screen, check the box that says "Add python.exe to PATH" before clicking Install. After installing, restart PowerShell.

Step 2: Create the Workspace

You must create a dedicated folder for the WeChat bridge inside your OpenClaw skills directory. Run this in PowerShell:

mkdir -Force ~/.openclaw/skills/wechat

Step 3: The Manifest

Create a file named SKILL.md inside the ~/.openclaw/skills/wechat folder and paste the following:

---
name: "qcai-wechat"
description: "QCAI WeChat Bridge: Remote control your WeChat desktop via AI."
metadata:
  openclaw:
    emoji: "💬"
    category: "Communication"
    homepage: "./gui.html"
---

# QCAI WeChat Tool
This tool allows you to sync messages and send replies to WeChat groups or contacts.

## Commands

### `send`
Send a message to a specific contact or group.
- **Usage**: `python wechat_bridge.py --action send --who "Contact Name" --msg "Your message"`

### `sync`
Fetch the latest messages from a specific chat.
- **Usage**: `python wechat_bridge.py --action sync --who "Group Name"`

Step 4: The Logic Engine

Create a file named wechat_bridge.py in the same folder and paste this proper execution script:

import sys
import argparse
import json
from wxauto4 import WeChat

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--action', choices=['send', 'sync'], required=True)
    parser.add_argument('--who', required=True)
    parser.add_argument('--msg', help='Message to send')
    args = parser.parse_args()

    try:
        wx = WeChat()
        if args.action == 'send':
            if not args.msg:
                print(json.dumps({"status": "error", "message": "No message content"}))
                return
            wx.SendMsg(msg=args.msg, who=args.who)
            print(json.dumps({"status": "success", "detail": f"Sent to {args.who}"}))
            
        elif args.action == 'sync':
            # Correct method to get chat history in wxauto
            wx.ChatWith(args.who)
            msgs = wx.GetAllMessage()
            output = [{"sender": m[0], "content": m[1]} for m in msgs]
            print(json.dumps(output, ensure_ascii=False))
            
    except Exception as e:
        print(json.dumps({"status": "error", "message": str(e)}))

if __name__ == "__main__":
    main()

<script>
async function execute(action) {
    const who = document.getElementById('target').value;
    const msg = document.getElementById('message').value;
    const status = document.getElementById('status');
    
    if (!who) {
        alert("Please enter a Chat Name");
        return;
    }
    
    status.innerText = "Running command on Windows PC...";
    
    let cmd = `python wechat_bridge.py --action ${action} --who "${who}"`;
    if (action === 'send') cmd += ` --msg "${msg}"`;
    
    try {
        const resp = await fetch('/api/exec', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ cmd: cmd })
        });
        const data = await resp.json();
        status.innerText = action === 'send' ? "Sent!" : "Sync complete. Check logs.";
    } catch (e) {
        status.innerText = "Error: Could not connect to OpenClaw.";
    }
}
</script>
</body>
