💬 QCAI WeChat Bridge Setup 💬 QCAI 微信桥接设置

This guide allows you to control your Windows WeChat desktop client remotely using your OpenClaw Gateway. 本指南允许您通过 OpenClaw 网关远程控制您的 Windows 微信桌面客户端。

Requirements: 环境要求：
  • Windows PC with WeChat Desktop installed and logged in. 安装并登录了微信桌面版的 Windows 电脑。
  • Python 3.10+ and Git installed on your Windows machine. 在您的 Windows 机器上安装了 Python 3.10+ 和 Git。

Step 1: Install Automation Driver 步骤 1：安装自动化驱动

Open PowerShell or Command Prompt on your Windows PC and install the WeChat automation driver from the QCAI repository: 在您的 Windows 电脑上打开 PowerShell 或命令提示符，并从 QCAI 仓库安装微信自动化驱动： 

pip install git+https://github.com/qcai-net/wxauto4.git
Troubleshooting 'pip' or 'git' errors: 问题排查 ('pip' 或 'git' 错误):
1. If pip is missing:如果缺少 pip： Re-run the Python installer and check "Add python.exe to PATH". 重新运行 Python 安装程序 并勾选 "Add python.exe to PATH"。
2. If git is missing:如果缺少 git： Download and install Git for Windows to allow installation from GitHub. 下载并安装 Git for Windows 以允许从 GitHub 进行安装。
3. Fast Fix:快速修复： You can run winget install Python.Python.3 and winget install Git.Git in PowerShell to install both automatically. 您可以在 PowerShell 中运行 winget install Python.Python.3 和 winget install Git.Git 来自动安装两者。

Step 2: Create the Workspace 步骤 2：创建工作空间

You must create a dedicated folder for the WeChat bridge inside your OpenClaw skills directory. Run this in PowerShell: 您必须在 OpenClaw 技能目录中为微信桥接创建一个专用文件夹。在 PowerShell 中运行： 

mkdir -Force ~/.openclaw/workspace/skills/wechat

Step 3: The Manifest 步骤 3：清单文件 (Manifest)

Create a file named SKILL.md inside the ~/.openclaw/workspace/skills/wechat folder and paste the following: 在 ~/.openclaw/workspace/skills/wechat 文件夹中创建一个名为 SKILL.md 的文件并粘贴以下内容： 

---
name: "qcai-wechat"
description: "QCAI WeChat Bridge: Remote control your WeChat desktop via AI."
metadata: {"openclaw": {"emoji": "💬", "category": "Communication"}}
---

# QCAI WeChat Tool

This skill allows the OpenClaw Agent to sync messages and send replies to WeChat groups or contacts natively.

## When to use this skill

Invoke this skill automatically when the user asks about:
- Sending a message to someone on WeChat
- Reading, syncing, or fetching the latest messages from a WeChat group or contact
- Replying to a WeChat conversation

**Trigger phrases:** "Send a WeChat message", "Sync WeChat", "Read WeChat", "message on WeChat"

## Command

```bash
python {baseDir}/wechat_bridge.py --action "<action>" --who "<who>" --msg "<message>"
```

### Arguments

| Argument | Default | Description |
|---|---|---|
| `<action>` | — | MUST be either "send" or "sync" |
| `<who>` | — | The exact name of the WeChat contact or group |
| `<message>` | "" | The message to send (only required if action is 'send') |

## Usage examples

```bash
# Send a message to Charlotte Real Estate
python {baseDir}/wechat_bridge.py --action "send" --who "Charlotte Real Estate" --msg "I am on my way."

# Sync latest messages from Operations Group
python {baseDir}/wechat_bridge.py --action "sync" --who "Operations Group" --msg ""
```

## Output

The script returns a JSON structured response indicating success/failure, or a JSON array of recent messages.

Step 4: The Logic Engine 步骤 4：逻辑引擎

Create a file named wechat_bridge.py in the same folder and paste this proper execution script: 在同一文件夹中创建一个名为 wechat_bridge.py 的文件并粘贴这个正确的执行脚本： 

import sys
import argparse
import json
from wxauto4 import WeChat

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--action', choices=['send', 'sync'], required=True)
    parser.add_argument('--who', required=True)
    parser.add_argument('--msg', help='Message to send')
    args = parser.parse_args()

    try:
        wx = WeChat()
        if args.action == 'send':
            if not args.msg:
                print(json.dumps({"status": "error", "message": "No message content"}))
                return
            wx.SendMsg(msg=args.msg, who=args.who)
            print(json.dumps({"status": "success", "detail": f"Sent to {args.who}"}))
            
        elif args.action == 'sync':
            # Correct method to get chat history in wxauto
            wx.ChatWith(args.who)
            msgs = wx.GetAllMessage()
            output = [{"sender": m[0], "content": m[1]} for m in msgs]
            print(json.dumps(output, ensure_ascii=False))
            
    except Exception as e:
        print(json.dumps({"status": "error", "message": str(e)}))

if __name__ == "__main__":
    main()
